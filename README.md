## 📖 Introduction

**Yook** is a community-driven social network platform built as a personal full-stack project. The tagline says it all: *"The story of us, by us."*

Users can register for an account, write posts about anything on their mind, comment on others' posts, and browse an activity feed — all within a polished dark/light themed UI. The project was built to practice and demonstrate end-to-end web development skills across the full stack: a React front-end, a Node.js/Express REST API back-end, and a PostgreSQL database.

---

## ✨ Features

- **Authentication** — Secure user registration and login with session management. Admin accounts are supported via a secret key toggle on sign-up.
- **Feed & Sorting** — Browse all posts on the home page with sorting (Oldest to Newest, etc.) and configurable posts-per-page pagination.
- **Create Posts** — Logged-in users can publish posts via a "What's on your mind?" modal with a title and message body.
- **Comments** — Users can comment on any post and see all comments displayed in a side panel when viewing a post.
- **User Profiles** — Each user has a profile page showing their avatar, bio, location, and birthday. Users can edit their own profile (name, avatar URL, bio, location, birthday) but cannot modify other users' profiles.
- **Activity Pages** — View a user's full post and comment history in one place, accessible from their profile.
- **Public Profile Browsing** — Clicking on any user's name or handle navigates to their public profile page.
- **Theme Toggle** — Switch between Dark Mode and Light Mode at any time via the sidebar.

## 🎯 Project Purposes

This project was built with several learning goals in mind:

1. **Practice full-stack development** end-to-end — from database schema design to REST API construction to a fully interactive React front-end.
2. **Implement real authentication flows** — including secure password hashing, token-based auth.
3. **Work with a relational database** — designing and querying PostgreSQL tables for users, posts, comments, and activity logs.
4. **Build a production-quality UI** — a clean, responsive dark/light mode interface that mirrors the polish of real social platforms.
5. **Deploy a full-stack application** — getting both the client and server live and communicating in a production environment.
